# Voices Directory

Drop your character reference audio files here for zero-shot voice cloning.

### Supported Formats
- `.wav`, `.mp3`, `.m4a`, `.flac`, `.ogg`

### Best Practices for Cloning
1. **Duration**: 10 to 20 seconds of continuous speech.
2. **Quality**: Clean audio with minimal background noise, echo, or reverb.
3. **No Background Music**: Ensure there is no music or sound effects behind the speech.
4. **Naming**: Name your files clearly (e.g., `narrator.wav`, `mohan.wav`, `ravi.wav`).
5. After adding a file, click the **🔄 Refresh Voices** button in the Web UI to see it in the voice selection dropdown!
